Selectable list

Item 217

Five ways to show which item in a list is chosen, for the style guide's component list and first for the new game screen's civilizations. Click a row, or focus a list and use the arrow keys. Each demo is the same fixed-size sheet, so the selection never moves the sheet: compare a short story (Greece) with a long one (Egypt). Focus (the teal ring) and selection stay distinct in every option, as §4.4 requires.

A

Index card chosen

The rows are printed on a recessed well. The chosen one is pulled out like an index card: a sheet strip that slides 8 px out of the column onto a hard plinth, with the signal-orange index tab wiping in on its leading edge.

It is the guide's existing selection treatment (§4.4, §10.5) for cards, applied to rows, so a selected card and a selected row read the same.

Motion: slide + tab wipe, 200 ms machined. Sound: ui.selection.
B

Folder tab

The list is a column of folder tabs (§15.3 turned on its side). The chosen tab is the sheet itself: it opens into the detail with no rule between them, and a 3 px ink rail slides along its outer edge.

This option links the row most clearly to the text beside it, but it only works when the list sits beside its detail.

Motion: rail slides, 200 ms machined. Sound: none (sub-navigation).
C

Ledger line

Plain rows ruled by hairlines, as in a typeset register. The chosen line prints in inverse: an ink fill with sheet text.

It's the easiest to read at a glance and works in any list, but it's heavy: the ink block competes with the title and with Start.

Motion: fill, 120 ms. Sound: ui.selection.
D

Selector lamps

Each row has an indicator lamp. The chosen row's lamp is lit, like the positions of a rotary selector switch. It uses the right geometry (a circle for state) and it's quiet.

Quiet can be too weak, though: a 12 px lamp is a small cue on a large screen, and the lamps also look like radio buttons.

Motion: lamp-on 40 ms. Sound: none (the lamp is the latch).
E

Pointer

Plain rows beside a gutter with a hairline. A solid signal triangle (the guide's sign for direction) slides along the gutter to the chosen row, like the needle of a slide-rule dial.

It's light and has character, but the selection relies on a small mark plus the row's weight.

Motion: pointer slides, 200 ms machined. Sound: ui.selection.

Whichever look: a sheet that doesn't move

  • Fixed size. The sheet is as tall as the tallest civilization's detail, measured when the list is filled, so changing the selection never resizes or recentres it.
  • Footer pinned. The seed and Start sit at the foot of the sheet under a hairline (the guide's modal footer rule, §7.14), not straight after the text.
  • Print headings. "Rules" and "Home" set as label caps (Rules), so the detail reads as a printed sheet rather than one block of body text.
