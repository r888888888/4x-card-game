Sound export

Renders every sound token of the style guide (§14.1) with the specimen's synthesis (mcm-specimen.html, copied below) into the placeholder files the game plays (§16.10): 48 kHz, 16-bit, mono WAV, the transient at 0 ms, normalised so the peak sits at the token's level (0 dB = −26 dBFS). Level 1 tokens get four variants at the specimen's variant pitches, Level 2 two, Level 3 one; Level 2 and 3 files carry their own short room tail until the game has a shared reverb (§16.6). Save them under assets/sounds/ with the names shown.
