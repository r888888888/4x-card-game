Civic Planning Desk

The live specimen of the game's design as it is built: every token and component, in Night and Paper, with motion, Reduce motion and synthesized sound. When the game changes how something looks, moves or sounds, this page changes with it.

  • The board: strip, ready lamps, Realm, hand, rail, End turn
  • Colour, typography
  • Controls: keys, tabs, the lamp key, the selectable list, the divider tab
  • Resource strip: odometers and forecasts
  • Cards: hand, Realm, supply, identity, units
  • Feedback: tooltip, progress, flags, starburst, modal
  • Screens: Knowledge, a territory, the supply
  • Sound: every token, levels, repetition test

Mocks

mocks/ · options compared, then decided

Each page compares a few designs for one question. Once one is built, the specimen shows it; the page stays as the record of what was weighed and why. Open means its item isn't built yet; Chosen means a design was picked but nothing builds it yet.

Keeping it in order

For whoever adds the next page
  1. A new comparison goes in mocks/ as <topic>-options.html, copying its tokens from the specimen, and gets a row here.
  2. When an item builds the chosen design, it updates the specimen to match the game, and its row here to Built with the option and item.
  3. The specimen draws what the game does now; a mock may draw what it might do. When they disagree, the game and the specimen win.
  4. Tools that produce files for the game (like the sound exporter) go in tools/.
